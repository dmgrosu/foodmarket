## Request handlers

`/auth/register`, `/auth/resendConfirmation` and `PUT /user/activate/{userId}` show an empty `usecase` column — they delegate to a `domain/*/core/handler/*RequestHandler` instead of calling a use case directly. The handler owns the transaction boundary: it runs the use case's database write in its own transaction, then triggers the Mailjet call only after that write has committed. `POST /auth/confirmEmail` has no external-call side effect, so it calls `RegistrationConfirmUseCase` directly instead of going through a handler — see `conventions.md`.

## Anonymous access (SecurityConfig.securityFilterChain + JwtFilter.shouldNotFilter)

`permitAll`: `/auth/register`, `/auth/confirmEmail`, `/auth/resendConfirmation`, `/auth/login`, `/client/findByIdno`, `/v3/api-docs/**`, `/swagger-ui/**`, `/swagger-ui.html`. Everything else `authenticated()`.
No voter inspects the *resource* being accessed (e.g. order ownership) — only the coarse authenticated/admin distinction is enforced.

## No frontend consumer

`GET /order/getById/{orderId}`, `DELETE /order/deleteById/{orderId}`, `POST /order/getOrdersByPeriod`, `PUT /order/update`.
`getOrdersByPeriod` is the missing piece for the `/orders` stub component.

## No voter

`GET /storage` — `StorageController` injects no voter at all. It is still behind `authenticated()` at the filter-chain level.
`AuthAccessVoter#assertCanLogin` / `#assertCanRegister` / `#assertCanConfirmEmail` / `#assertCanResendConfirmation` exist but have empty bodies (deliberate — public endpoints).
`ClientAccessVoter#assertCanFindByIdno` calls `assertUserIsAuthenticated()` even though `SecurityConfig` permits the endpoint anonymously.

## Admin-only (Role.ADMIN)

`GET /user/search` and `PUT /user/activate/{userId}` are the only admin endpoints. There is **no path-based rule** for either in `SecurityConfig` — enforcement is solely `UserAccessVoter#assertCanSearch` / `#assertCanActivate` -> `AccessVoter.assertUserIsAdmin()`, so a forgotten assert would leave either open to any authenticated user.
